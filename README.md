# Medimate

Medimate is a Java-based application designed to assist users in managing their medication schedules effectively. This repository contains the source code and necessary files to build and run the application. Additionally, Medimate incorporates AI capabilities, allowing users to upload test reports, which are processed using Optical Character Recognition (OCR) and then analyzed by a Large Language Model (LLM) to generate insightful responses.


- User-friendly interface for managing medications
- Schedule reminders for medication intake
- Track medication history
- Supports multiple users
- **AI Integration**: Upload test reports for analysis
- **OCR Functionality**: Extract text from uploaded documents
- **LLM Responses**: Generate insights and recommendations based on extracted text
